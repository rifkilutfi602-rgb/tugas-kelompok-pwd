# tugas-kelompok-pwd

1. Setelah clone repo open di vscode terus buat branch (wajib) sesuai pembagian tugas, ex : fitur-transaksi. lalu switch baru di modifikasi file sesuai bagian

command :
-git switch main
-git pull
-git switch -c fitur-transaksi /ubah sesuai bagian masing masing

setelah itu tinggal modifikasi file nya

2. Setelah modifikasi dan sudah fix semua simpan pwerubahan modifikasi

command :
-git add .
-git commit -m "pesan bebas"
-git push -u origin fitur-transaksi /ubah sesuai bagian masing masing

3. Setelah di simpan lakukan pull request di github
    1. Buka repository di GitHub.
    2. Klik Compare & pull request jika muncul, atau buka menu Pull requests lalu pilih New pull request.
    3. Pastikan branch tujuan adalah main dan branch sumber adalah branch fitur anggota.
    4. Tulis ringkasan perubahan.

4. Setelah sudah tinggal PM yang mengeksekusi
